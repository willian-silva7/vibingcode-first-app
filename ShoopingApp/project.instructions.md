# Project instructions

- Keep this project in plain JavaScript using CommonJS modules.
- Prefer small, readable functions and avoid unnecessary abstractions.
- Maintain the existing file responsibilities: grid generation, word detection, and date matching.
- Validate input types and fail with clear errors when misuse is detected.
- Preserve the current Node.js-friendly style and avoid installing new libraries unless they are clearly required.
- When changing behavior, make the smallest possible fix that matches the original intent of the project.
